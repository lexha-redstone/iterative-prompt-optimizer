# DESIGN & AESTHETIC RULEBOOK

## 1. Layout & Information Architecture (The "Invisible Grid")
- **Mandatory Success (5.0):** Top designs use pure, generous whitespace and mathematical symmetry (e.g., perfectly balanced 2x2 grids, perfectly aligned 1x4 horizontal/vertical lists). 
- **Dividers & Containers:** Generous whitespace is the ONLY acceptable separator. Explicit drawn lines, bounding boxes, or colored background panels are penalizable.
- **Asymmetry (ZERO TOLERANCE):** Never accept asymmetrical grids (e.g., 3 items on left, 1 on right), erratic staggered rows, or snaking flowcharts for simple sequential data.

## 2. Art Style & Color Palette
- **Strict Icon Uniformity (ZERO TOLERANCE):** All icons MUST belong to the exact same visual family. You must use EITHER 100% solid-fill flat vectors OR 100% uniform line-art. Mixing styles is an automatic zero.
- **Color Discipline:** Primary and secondary body text MUST be neutral (warm near-black, charcoal, or dark mid-grey). Accent colors are reserved strictly for icons and data. 
- **FORBIDDEN Elements (ZERO TOLERANCE):** Absolutely NO gradients, NO drop shadows, NO 3D effects. Absolutely NO human figures, faces, or body parts (detailed or silhouette).

## 3. Typography & Text Mechanics
- **Spelling & Artifacts (ZERO TOLERANCE):** AI-generated text must be flawless. Absolutely NO prompt leaks (e.g., "Heavy Poppins"), NO axis chart artifacts (e.g., "0px", "2px"), and NO duplicated words (e.g., "the the").
- **Duplication/Filler (ZERO TOLERANCE):** Do NOT artificially duplicate the user's single-line text (e.g., "Unclear expectations / Unclear expectations") to fake a Header+Subtext visual hierarchy.
- **Casing Rules:** STRICTLY Sentence case for all headers and body text. Title Case is a minor flaw. Stylized all-lowercase for primary headers is a major failure.

## 4. Summarization & Text Density
- **Essential Extraction:** An infographic is not a document. The design MUST expertly summarize the user's input dataset, extracting only the essential core concepts, primary figures, and key takeaways into concise titles and brief descriptions.
- **Wall of Text (ZERO TOLERANCE):** Copy-pasting massive blocks of text, full paragraphs, or failing to condense the source material is a critical failure. The text must be highly scannable.
- **Zero Hallucination (ZERO TOLERANCE):** While summarizing, the design must not invent new meaning. No extra commentary, no invented stats, no hallucinated bullet points, no new columns (e.g., "Insights").

## 5. Data Visualization & Chart Necessity
You must strictly evaluate whether the data provided explicitly demands a chart. Forced or unnecessary charts are a sign of poor design judgment.
- **Valid Chart Usage:** Bar charts, graphs, or timelines should ONLY be used for complex numerical datasets, quantitative growth, or distinct mathematical comparisons (e.g., visualizing metric shifts like 40k vs 95k traffic).
- **Invalid Chart Usage:** NEVER force qualitative, conceptual information (e.g., audience availability, rollout phases, basic lists) into a pseudo-graph or progress bar with fabricated axes. Simple text and icons must be used for non-numerical concepts.

# STRICT SCORING & DEDUCTION RUBRIC
You MUST apply these exact mathematical deductions. Start at 5.0 for each category and subtract. **If multiple non-AUTO flaws exist in a category, cumulatively subtract all applicable penalties.** If an "AUTO" rule is triggered, the final score for that category is exactly 0.0. Scores cannot drop below 0.0.

**C1: Layout & Architecture**
- [ 5.0 ] Perfect, balanced, symmetrical grid using generous whitespace for separation.
- [ -1.5 ] Uses explicit dividing lines or bounding boxes instead of pure whitespace.
- [ 0.0 AUTO ] Asymmetrical grids (e.g., 3-1 split), erratic multi-row flows, completely broken structures, or overly complex snaking flowcharts.

**C2: Art Style & Color**
- [ 5.0 ] Flawlessly unified vector style (all solid OR all line); highly disciplined colors.
- [ -2.0 ] Accent colors (e.g., blue, green) improperly applied directly to structural headers or body text.
- [ 0.0 AUTO ] Mixed icon styles (e.g., line-art placed next to solid silhouettes).
- [ 0.0 AUTO ] Presence of Gradients, 3D effects, or drop shadows.
- [ 0.0 AUTO ] Presence of human figures, faces, hands, or detailed character illustrations.

**C3: Typography & Mechanics**
- [ 5.0 ] Flawless typography, perfect spelling, strict Sentence case.
- [ -0.5 ] Uses Title Case for headers instead of Sentence case.
- [ -1.0 ] Includes terminal punctuation at the end of labels or titles.
- [ -3.0 ] Uses stylized all-lowercase formatting for primary structural text.
- [ 0.0 AUTO ] Typographical errors, spelling mistakes, or duplicated words ("the the").
- [ 0.0 AUTO ] Prompt leaks, UI chart artifacts ("0px"), or duplicating source text to fake a visual hierarchy.

**C4: Summarization & Text Density**
- [ 5.0 ] Flawless summarization: expertly distills a dense input into highly scannable, punchy headers and brief text without losing the core message.
- [ -2.0 ] Missing a clear, overarching Main Title that defines the infographic's topic.
- [ -2.0 ] Poor text economy: text blocks are too long or dense, requiring heavy reading rather than quick visual scanning.
- [ -3.0 ] Redundant data display (repeating the exact same numbers in a chart and sidebar).
- [ 0.0 AUTO ] Wall of Text: Copy-pasting entire paragraphs or massive blocks of the user's input, entirely defeating the purpose of an infographic.
- [ 0.0 AUTO ] Hallucinated statistics, fabricating entire sections, or completely dropping the main overarching topic.

**C5: Data Visualization & Chart Necessity**
- [ 5.0 ] Perfectly Justified OR Correctly Omitted: A chart is present and flawlessly visualizes complex quantitative data without issues, OR the data does not require a chart and none is present.
- [ -2.0 ] Missing Necessary Chart: The source data contains complex numerical comparisons that explicitly require a chart, but the design relies only on text/icons.
- [ 0.0 AUTO ] Unnecessary/Forced Chart: A chart is present but entirely unjustified. The source data is qualitative/conceptual (e.g., availability stages, simple lists), yet the design forces it into a pseudo-graph or chart format.
