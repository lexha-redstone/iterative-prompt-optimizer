## 1. Isometric Projection & Structural Geometry (C1)
- **Macro-Structure Supremacy:** Top designs use clean, distinct isometric blocks/islands. Foundational structures must adhere strictly to a 30-degree isometric projection.
- **Structural Overlays vs. UI Connectors:** Massive 2D flat elements that *replace* structural depth or traverse/break the core 3D plane auto-fail. However, flat abstract UI lines/arrows that serve strictly as logical flow connectors *between* correctly rendered 3D islands are treated as localized UI deductions, not structural spatial breakdowns.
- **UI Pollution:** Massive front-facing flat elements (e.g., giant 2D speech bubbles, un-warped ribbons) floating over the space severely degrade spatial depth and trigger low caps.

## 2. Pixel Art Authenticity (C2)
- **Fake Pixel Medium Auto-Fail:** Standard digital drawings that use post-processing digital halftones, unaligned screentones, soft anti-aliasing, or high-res noise filters to "fake" a retro look instantly fail C2.
- **Mixels Exemption:** Core architectural sprites must maintain a unified pixel scale. However, stylized flat UI overlays (thick arrows, banners, HUD text) are exempt from strict pixel-scale matching. Do NOT evaluate text typography in C2.

## 3. Typography & Text Mechanics (C3)
- **Extreme Typography Constraints:** Blatant AI gibberish or severe typos completely invalidate the category.
- **Spatial Housing:** Text must respect the isometric space or act as clean HUD elements. Hiding text inside massive flat 2D panels or comic speech bubbles that shatter the isometric illusion results in extreme penalties.

## 4. Information Architecture & Data Integration (C4)
- **Modular Islands Anchors:** Designs that successfully segregate primary data points onto discrete, non-overlapping, breathable isometric platforms MUST receive high scores, overriding penalties for flat title banners.
- **Spaghetti Architecture & Clutter:** Tangled meshes of overlapping labels, crisscrossing arrows, and suffocated negative space are heavily penalized or auto-failed.

## 5. Lighting, Palette & Aesthetic Execution (C5)
- **Authentic Shading Anchor:** Execution of crisp, pixel-perfect dithering (e.g., 1-bit checkerboarding) across the main macro-structures secures high scores, forgiving minor unshaded props.
- **Geometric Prerequisite:** Lighting cannot be evaluated on flat planes. If the primary focal structure is a flat 2D object, isometric lighting has failed.

# STRICT SCORING & DEDUCTION RUBRIC
You MUST apply these exact mathematical modifiers. Start at 5.0 for each category. Apply caps first, then apply bonuses/deductions cumulatively. Scores cannot drop below 0.0 or exceed 5.0.

**C2: Pixel Art Authenticity (Exclude Typography Here)**

- [ 0.0 AUTO ] Mixels (Core Architecture): Noticeably mismatched pixel scales between core props, buildings, or the environment. (Stylized UI overlays/arrows are exempt).

**C3: Typography & Text Mechanics**
- [ 5.0 BASE ] Highly legible pixel-font text blocks with perfect spelling.
- [ 1.5 MAX CAP ] Cascaded Structural Penalty: If the image triggers the "Literal Megastructure Auto-Fail" in C4, C3 is capped at 1.5, as the required 3D foundation for isometric text does not exist.

- [ 1.0 MAX CAP ] UI Overlay Focus: Primary stage labels or core data points are displayed on flat, front-facing 2D banners/ribbons instead of integrated into the isometric space.
- [ -1.5 ] Perspective-Warped Text: Forcibly slanted/skewed standard vector text mapped to 3D planes.

- [ 0.0 AUTO ] Gibberish & Spatial Break: Auto-fail if text contains blatant AI gibberish/alphabet-soup, OR if core text is housed in massive 2D panels/speech bubbles that actively ignore the isometric plane.

**C4: Information Architecture & Data Integration**
- [ 5.0 BASE / 4.0 MIN ANCHOR ] Modular Clarity: Successfully isolates distinct infographic data points onto discrete, well-separated isometric platforms. (If achieved, C4 cannot score below 4.0, overriding any penalties for minor flat UI containers).

- [ -1.5 ] Minor Flat Flow Overlays: Using non-structural 2D connective lines/arrows between distinct modular 3D platforms.
- [ 0.0 AUTO ] Visual Chaos (Spaghetti Auto-Fail): Flow is destroyed by crisscrossing macro-arrows, conflicting top-down elements, and massive spatial clutter rendering the infographic unreadable.
- [ 0.0 AUTO ] Literal Megastructure Auto-Fail: The design uses a massive, centralized literal 2D diagram (e.g., a literal flat drawing of a funnel) instead of translating concepts into modular 3D platforms.

**C5: Lighting, Palette & Aesthetic Execution**
- [ 5.0 BASE / 4.0 MIN ANCHOR ] Authentic Shading Anchor: Core macro-structures demonstrate authentic, crisp, pixel-perfect dithering (e.g., 1-bit checkerboarding). (If achieved, C5 cannot score below 4.0).
- [ +1.5 BONUS ] Monochrome Discipline: Strict adherence to a 1-bit/dual-tone palette with dithered/flat structural planes offsets deductions for minor unshaded props.
- [ -3.0 ] Digital UI Lighting: Modern UI drop-shadows, glow effects, or faux-ambient occlusion.
- [ 0.0 AUTO ] Geometric Prerequisite Auto-Fail: The primary focal structure triggers a C1 failure for being a flat 2D object (2D dithering does not equal isometric lighting).
- [ 0.0 AUTO ] Faux-Shading Filters: Reliance on global digital screentones or unaligned noise masks to imply depth.
