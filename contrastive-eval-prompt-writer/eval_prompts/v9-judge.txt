# DESIGN & AESTHETIC RULEBOOK

## 1. Isometric Projection & Structural Geometry (C1)
- **Macro-Structure Supremacy:** Top designs use clean, distinct isometric blocks/islands. All foundational structures and primary illustrative focal points must adhere strictly to a 30-degree isometric projection. 
- **Zero-Tolerance for Orthographic Contamination:** Including top-down perspective elements, massive 2D flat structural overlays, or massive front-facing props (e.g., clipboards, gears) fundamentally shatters the isometric illusion and triggers severe caps or auto-failures. 
- **Embedded Prop Strictness:** Any UI element, icon, or minor prop pasted onto a 3D plane MUST undergo proper 30-degree isometric perspective distortion.

## 2. Pixel Art Authenticity (C2)
- **Isolate Typography:** Do NOT evaluate the rendering style of text/fonts in this category. C2 evaluates the artwork and environment ONLY. 
- **Zero-Tolerance for "Mixels":** Pixel scale must be absolutely unified across the entire image. If an image contains drastically different base pixel sizes (e.g., tiny high-res pixels next to chunky low-res structural pixels), it instantly fails.
- **Dithering vs. Noise:** Uniform, grid-aligned checkerboard or stipple patterns are authentic 1-bit/retro shading techniques and must NEVER trigger the "Global Noise" penalty. True noise (unaligned digital halftones, screentones over vector art, or soft anti-aliasing) is an instant failure.

## 3. Typography & Text Mechanics (C3)
- **Extreme Typography Constraints:** Text must be perfectly spelled, legible, and structurally cohesive. Blatant AI gibberish, alphabet-soup, or severe typos in ANY text (primary or environmental) entirely invalidates the asset.
- **Medium Aesthetic Integration:** Pixel art requires pixel fonts. Smooth, modern, anti-aliased vector text (e.g., Arial) fails the aesthetic mandate and is severely hard-capped.
- **Perspective & Container Mechanics:** Text must be housed properly within the 3D space. Using flat 2D comic speech bubbles or heavily skewing/warping 2D vector text to fit angled 3D surfaces are major violations. Text pixel scale must match the global art pixel scale.

## 4. Information Architecture & Data Integration (C4)
- **Modular Islands Anchor (Mandatory 5.0 Requirement):** A top score is reserved ONLY for designs that utilize distinct, well-separated isometric platforms/islands with significant negative space, allowing the viewer to parse information linearly.
- **Literal vs. Abstract:** Translating abstract 2D concepts into elevated 3D platforms is required. Relying on massive literal 2D diagrams (e.g., a literal flat drawing of a funnel) dominating the canvas is an immediate failure.
- **Clutter & Scannability:** Spaghetti architecture, dense megastructures lacking breathing room, or confusing flows heavily restrict the maximum score.

## 5. Lighting, Palette & Aesthetic Execution (C5)
- **Lighting Mandates:** Standard palettes require 3 distinct, flat planes of light (Highlight, Midtone, Shadow). 1-Bit/Monochromatic palettes use varying densities of authentic pixel dithering. 
- **1-Bit Constraint Exemption:** In 1-bit/monochromatic pixel art, applying dither-density shading to environmental planes while leaving small character sprites flat is a highly authentic constraint-based stylistic choice and incurs no penalty.

# STRICT SCORING & DEDUCTION RUBRIC
You MUST apply these exact mathematical modifiers. Start at 5.0 for each category and apply bonuses/deductions. If multiple non-AUTO flaws exist, cumulatively subtract. If an "AUTO" rule is triggered, the final score for that category is exactly 0.0. Scores cannot drop below 0.0.

**C1: Isometric Layout & Structural Geometry**
- [ 5.0 BASE ] Perfect 30-degree isometric projection with distinct geometric foundations and flawlessly distorted props.
- [ -1.0 per instance ] Embedded Flat Prop: Each instance of a flat 2D icon or UI element pasted onto a 3D plane without proper isometric distortion. 
- [ 2.0 MAX CAP ] Flat Primary Focal Points: If primary illustrative focal points (e.g., character props, large charts, clocks) are drawn in flat 2D orthographic perspective rather than mapped to the isometric grid, cap C1 at 2.0.
- [ 1.5 MAX CAP ] Pervasive Orthographic Elements: If the composition relies on massive flat 2D shapes (e.g., massive front-facing clipboards, gears, large UI panels) embedded physically in the 3D space, cap C1 at 1.5.
- [ 0.0 AUTO ] Spatial Geometry Breakdown: Automatically fail if the image mixes top-down perspectives (e.g., top-down vortexes) or relies on massive flat 2D structural overlays (e.g., giant flow arrows spanning the canvas) that ignore the 3D grid entirely.

**C2: Pixel Art Authenticity (Exclude Text Typography from Evaluation Here)**
- [ 5.0 BASE ] Flawless, uniform pixel scale across the entire image with authentic aliasing. Dithering is precise and grid-aligned.
- [ 0.0 AUTO ] Mixels: Image contains noticeably mismatched pixel scales (drastically different base pixel sizes clashing between props, environment, and details).
- [ 0.0 AUTO ] Smooth Art / Anti-Aliased Edges: The undeniable presence of soft anti-aliased edges, smooth gradients, or high-res digital brush strokes.
- [ 0.0 AUTO ] Global Noise / False Dithering: Unaligned, global halftone/noise filters or screentone gradients laid over vector art to fake a retro look. (Note: Grid-aligned checkerboard dithering is exempt and authentic).

**C3: Typography & Text Mechanics**
- [ 5.0 BASE ] Highly legible pixel-font text blocks with flawless transcription, perfect spelling, and matched pixel resolution.
- [ -0.5 ] Minor Typo: A single dropped/hallucinated word in otherwise structurally perfect secondary text. (-0.5 per instance).
- [ -1.5 ] 2D Text Containers: Text is housed in flat 2D elements like traditional comic speech bubbles or front-facing UI banners that ignore the established isometric perspective.
- [ -1.5 ] Perspective-Warped / Skewed Text: Standard typography forcibly slanted, skewed, or rotated artificially to fit an isometric plane.
- [ -3.0 ] Font Resolution Mismatch: Text font resolution/pixel size drastically differs from the global pixel scale of the artwork.
- [ 1.0 MAX CAP ] Vector Typography Baseline: If standard, anti-aliased, or smooth modern vector text is detected instead of a crisp aliased pixel font, hard-cap C3 at 1.0 maximum, prior to any spelling deductions.
- [ 0.0 AUTO ] Gibberish & Severe Hallucination: The primary title has a typo, OR environmental/secondary text contains blatant gibberish, severe misspellings, or AI alphabet-soup.

**C4: Information Architecture & Data Integration**
- [ 5.0 BASE / MANDATORY SUCCESS ANCHOR ] Flawlessly separates distinct data onto discrete isometric platforms/islands surrounded by clear negative space.
- [ +2.0 BONUS ] Voxelized Conceptual Integration: Offsets up to 2.0 points of deductions if abstract 2D flowcharts/funnels are perfectly transformed into discrete, physically elevated 3D isometric platforms.
- [ -0.5 ] Minor Flat Flow Overlays: Using non-structural 2D connective lines/arrows between distinct modular 3D platforms.
- [ 3.0 MAX CAP ] Clutter and Scannability Rule: The infographic suffers from severe visual clutter, overlapping modular blocks, or lacks distinct negative space between primary data steps.
- [ 0.0 AUTO ] Destructive Macro-Overlays / Spaghetti Auto-Fail: Tangling distinct points into a single confusing megastructure or relying on massive flat 2D arrows spanning across the canvas to force reading flow.
- [ 0.0 AUTO ] Literal Megastructure Auto-Fail: The design relies on a massive, centralized 2D diagram (e.g., a literal flat drawing of a funnel or flat chart) instead of translating the concept into decentralized, modular 3D isometric platforms.

**C5: Lighting, Palette & Aesthetic Execution**
- [ 5.0 BASE ] Flawless execution of strict 3-tone lighting (highlight, midtone, core shadow faces) or authentic structure-aware pixel dithering.
- [ 0.0 EXEMPTION ] 1-Bit Authentic Constraint: Flat character sprites on fully shaded/dithered environmental planes in 1-bit or monochromatic palettes.
- [ 2.0 - 3.0 BASELINE FLOOR ] Partial Execution: Foundational macro-structures use authentic lighting, but minor environmental props lack shading.
- [ -3.0 ] Digital UI Lighting: Use of modern UI drop-shadows, glow effects, or faux-ambient occlusion.
- [ 0.0 AUTO ] Faux-Shading Filters: Reliance on global digital screentones, halftones over vectors, or unaligned noise masks to imply depth.
- [ 0.0 AUTO ] Merged Planes / Flat Line-Art: Base isometric geometry fails to display clear, distinct planes of light or relies entirely on unshaded flat vector line-art.
